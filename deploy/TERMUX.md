# Бот на старом Android-телефоне (Termux)

Подробная инструкция: как превратить старый телефон в маленький сервер для бота.
Подходит **Android 7 или новее**. Телефон будет работать, пока он включён, заряжен и в Wi-Fi.

> На Android 5–6 современный Python в Termux поставить нельзя (поддержку пакетов прекратили в 2020 году) — этот путь не подойдёт.

---

## Шаг 1. Поставьте Termux

Скачайте **Termux** из одного из двух мест:

- [F-Droid](https://f-droid.org/packages/com.termux/) — нажмите «Download APK»;
- [github.com/termux/termux-app/releases](https://github.com/termux/termux-app/releases) — файл `apt-android-7` (universal или под вашу архитектуру).

**Не берите версию из Google Play** — она экспериментальная и многого не умеет.

Дополнительно (по желанию, но полезно) поставьте оттуда же:

- **Termux:API** — нужен для команды `termux-wake-lock` (не даёт телефону усыпить бота);
- **Termux:Boot** — нужен для автозапуска бота после перезагрузки телефона.

Важно: все APK ставьте из **одного источника** (или всё из F-Droid, или всё из GitHub) — иначе Android откажется их устанавливать.

## Шаг 2. Дайте Termux доступ к памяти телефона

Откройте Termux и выполните:

```
termux-setup-storage
```

На вопрос ответьте `y` и разрешите доступ в системном окне. Появится папка `~/storage` — через неё Termux видит «Загрузки», фото и т.д.

## Шаг 3. Перенесите проект на телефон

**Способ А — кабелем (проще).** Подключите телефон к компьютеру, разрешите доступ к файлам и скопируйте папку `game-news-bot` в папку **Download** памяти телефона.

**Способ Б — через Telegram или облако.** Отправьте себе архив `game-news-bot.zip`, скачайте его на телефон и распакуйте (ZArchiver или встроенный файловый менеджер) в **Download**.

Проверьте, что папка видна из Termux:

```
ls /sdcard/Download/game-news-bot
```

Должны появиться `main.py`, `gamebot`, `deploy`, `requirements.txt` и другие файлы.

## Шаг 4. Установите всё одной командой

Перейдите в папку проекта и запустите скрипт:

```
cd /sdcard/Download/game-news-bot
bash deploy/termux-setup.sh
```

Скрипт сам поставит Python, ffmpeg, библиотеку картинок (`python-pillow`) и зависимости проекта. Это займёт несколько минут — телефону нужно скачать пакеты.

## Шаг 5. Заполните настройки

```
nano .env
```

Нужны две строки:

```
TELEGRAM_BOT_TOKEN=токен-от-BotFather
TELEGRAM_CHANNEL_ID=@gameworld2029
```

- Если вы распаковывали готовый архив, `.env` уже заполнен — просто проверьте.
- В nano сохранить: `Ctrl+O`, затем `Enter`; выйти: `Ctrl+X`.
- Вставлять текст в Termux: **долгое нажатие по экрану → Paste**.

Проверка настроек:

```
python main.py --check
```

Должно быть «Всё готово к запуску!».

## Шаг 6. Запустите бота

```
termux-wake-lock
mkdir -p logs
nohup python main.py >> logs/termux.log 2>&1 &
```

- `termux-wake-lock` работает, если установлен плагин **Termux:API**. Без него просто не давайте телефону уходить в глубокий сон (см. шаг 7).
- `nohup ... &` — запуск в фоне: можно закрыть Termux, бот продолжит работать.

Проверить, что работает:

```
pgrep -fl "python main.py"
tail -f logs/termux.log      # выход: Ctrl+C
```

Остановить:

```
pkill -f "python main.py"
```

## Шаг 7. Не дайте Android убить бота

Это главная морока с телефонами — Android любит «экономить батарею» и прибивать фоновые процессы.

1. **Настройки → Приложения → Termux → Батарея → «Без ограничений»** (на разных прошивках пункт называется по-разному: «Не ограничивать», «Разрешить работу в фоне»).
2. **Android 12 и новее:** включите «Для разработчиков» (Настройки → О телефоне → 7 раз нажать «Номер сборки»), затем в меню для разработчиков найдите **«Отключить ограничения дочерних процессов»** и включите. Без этого периодически будет появляться `[Process completed (signal 9)]` и бот умрёт.
3. Держите телефон **на зарядке**: при разряде Android агрессивнее убивает процессы.
4. На некоторых прошивках (Xiaomi, Huawei, Samsung) есть отдельные «оптимизаторы» — добавьте Termux в исключения. Подсказки для вашей модели: [dontkillmyapp.com](https://dontkillmyapp.com/).

## Шаг 8. Автозапуск после перезагрузки

1. Установите **Termux:Boot** (из того же источника, что и Termux).
2. Один раз откройте приложение Termux:Boot, чтобы оно зарегистрировалось.
3. Создайте скрипт запуска:

```
mkdir -p ~/.termux/boot
nano ~/.termux/boot/bot.sh
```

Вставьте:

```
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
cd /sdcard/Download/game-news-bot
mkdir -p logs
nohup python main.py >> logs/termux.log 2>&1 &
```

4. Сделайте файл исполняемым:

```
chmod +x ~/.termux/boot/bot.sh
```

Теперь после перезагрузки телефона бот поднимется сам (с задержкой в минуту-другую).

## Шаг 9. Советы для слабого телефона

В `.env` можно снизить нагрузку:

| Параметр | Значение | Зачем |
|---|---|---|
| `SEND_TRAILERS` | `false` | Не обрабатывать видео — самая тяжёлая часть |
| `USE_FFMPEG` | `false` | То же самое |
| `MAX_SCREENSHOTS` | `1` | Меньше картинок — меньше памяти |
| `POST_INTERVAL_MINUTES` | `120` | Реже посты — меньше нагрузки |

После правок `.env` перезапустите бота (шаг 6: `pkill`, затем снова запуск).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `bash: deploy/termux-setup.sh: No such file or directory` | Вы не в папке проекта. Выполните `cd /sdcard/Download/game-news-bot` и повторите |
| `Permission denied` при доступе к `/sdcard` | Заново выполните `termux-setup-storage` и разрешите доступ |
| `[Process completed (signal 9)]` | Android убил процесс — шаг 7, пункт 2 |
| `pkg: command not found` | Вы не в Termux (или Termux не установился корректно) |
| `pip` не может скачать пакеты | Проверьте Wi-Fi, повторите команду; иногда помогает `pkg update` |
| Бот молчит, в логе пусто | Проверьте `pgrep -fl "python main.py"` — процесс мог не запуститься |
| Токен утёк | @BotFather → `/revoke` → получить новый и вписать в `.env` |

## Честно о надёжности

Телефон — хороший «бесплатный сервер, который уже есть». Но он не заменяет VPS:

- Android может убить процесс даже со всеми настройками (особенно на Xiaomi/Huawei);
- пропал Wi-Fi или сел аккумулятор — бот стоит;
- телефон греется, а батарея от постоянной зарядки изнашивается;
- физически доступен детям/домашним — легко выключить.

Для «попробовать и посмотреть» — отлично. Для канала, который должен работать годами, надёжнее Oracle Cloud Always Free (см. README, Вариант Б) или дешёвый VPS.
