# Бот игровых новостей для Telegram-канала

Бот сам находит свежие игровые новости, оформляет пост и публикует его в вашем канале по расписанию. Вам ничего не нужно присылать вручную.

**Что он умеет**

- Берёт из **Steam** (официальные публичные страницы магазина, ключ не нужен): релизы, анонсы, раздачи бесплатных игр, большие скидки. Описание на русском, цены в нескольких валютах, скриншоты и трейлер.
- Берёт новости из **RSS-лент** игровых сайтов (список — в файле `feeds.txt`).
- Оформляет пост как в вашем образце: жирный заголовок → короткое описание → цены → подпись канала. Картинки и трейлер идут одним альбомом.
- Не публикует одно и то же дважды (помнит всё в файле `data/bot.db`), пропускает похожие новости из разных источников и игры 18+.
- Под каждым постом ставит кнопку **«Подписаться на канал»** и считает, сколько людей пришло по каждой пригласительной ссылке (команда `python main.py --stats`).
- Не падает: если сайт или Telegram не отвечает, бот пишет об этом в лог, ждёт и пробует снова.

## Пошаговая инструкция для новичка

### Шаг 1. Установите Python

Нужен Python версии **3.10 или новее**.

- **Windows:** скачайте с [python.org/downloads](https://www.python.org/downloads/). При установке **обязательно поставьте галочку «Add Python to PATH»**.
- **Linux (Ubuntu/Debian):** `sudo apt update && sudo apt install -y python3 python3-venv python3-pip`
- **macOS:** `brew install python` или установщик с python.org.

Проверка: откройте терминал (на Windows — «Командную строку» или PowerShell) и введите `python --version` (на Linux/macOS: `python3 --version`).

### Шаг 2. Создайте бота у @BotFather

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте команду `/newbot`.
3. Введите **название** бота (любое, например «Игровые новости»).
4. Введите **имя пользователя** бота — латиницей и обязательно с `bot` на конце, например `my_game_news_bot`.
5. BotFather пришлёт **токен** — длинную строку вида `123456789:AAH...`. Скопируйте её. **Никому не показывайте токен** — с ним можно управлять вашим ботом.

### Шаг 3. Добавьте бота администратором в канал

1. Откройте свой канал → название канала вверху → **«Управление каналом»** (значок карандаша) → **«Администраторы»** → **«Добавить администратора»**.
2. Найдите своего бота по имени пользователя и выберите его.
3. Оставьте включённым право **«Публикация сообщений»** (остальные можно выключить) и сохраните.

**Как указать канал в настройках:**

- Публичный канал (есть ссылка `t.me/имя`): пишите `@имя`.
- Закрытый канал: нужен числовой ID вида `-1001234567890`. Самый простой способ: временно сделайте канал публичным (дайте ему имя), впишите `@имя` в настройки и выполните шаг 6 — команда проверки покажет числовой ID. Потом вернёте канал в закрытый и замените `@имя` на этот ID.

### Шаг 4. Скачайте проект и установите библиотеки

Распакуйте архив с проектом, например, в папку `game-news-bot`. Откройте терминал **внутри этой папки** и выполните:

**Windows (PowerShell):**
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**Linux / macOS:**
```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

(Слово `venv` — это «отдельная комнатка» для библиотек проекта, чтобы они ничего не ломали в системе. Каждый раз, когда открываете новый терминал, сначала снова выполняйте `venv\Scripts\activate` или `source venv/bin/activate`.)

### Шаг 5. Заполните настройки

1. Скопируйте файл `.env.example` под именем **`.env`**:
   - Windows: `copy .env.example .env`
   - Linux/macOS: `cp .env.example .env`
2. Откройте `.env` в любом текстовом редакторе (Блокнот подойдёт) и заполните **две строки**:
   ```
   TELEGRAM_BOT_TOKEN=токен-от-BotFather
   TELEGRAM_CHANNEL_ID=@имя_вашего_канала
   ```
3. Подпись под постами задаётся строкой `CHANNEL_SIGNATURE=@имя_вашего_канала`. Часовой пояс — `TIMEZONE`. Частота публикаций — `POST_INTERVAL_MINUTES` (в минутах). Все остальные настройки уже выставлены разумно, и у каждой в файле есть пояснение.

> Файл `.env` содержит секреты. Не отправляйте его другим людям и не выкладывайте в интернет.

### Шаг 6. Проверьте, что всё работает

```
python main.py --check
```
Бот проверит токен, доступ к каналу, Steam, RSS-ленты и ffmpeg и по-русски скажет, что исправить. Здесь же покажет числовой ID канала.

Дальше три безопасные пробы:

```
python main.py --ping                 # отправит в канал «Бот подключён»
python main.py --once --dry-run       # покажет пример поста в окне терминала, ничего не публикуя
python main.py --once                 # опубликует один настоящий пост прямо сейчас
```

Если пост в канале выглядит так, как вы хотели, — переходите к запуску.

### Шаг 7 (рекомендуется). Установите ffmpeg — для видео-трейлеров

Steam больше не отдаёт трейлеры обычными видеофайлами, только потоком. Чтобы превратить поток в видео, которое Telegram покажет прямо в посте, нужна бесплатная программа **ffmpeg**. Без неё бот работает, но посты выходят **без видео** (только скриншоты).

- **Ubuntu/Debian:** `sudo apt install -y ffmpeg`
- **Windows:** в PowerShell `winget install Gyan.FFmpeg`, затем закройте и снова откройте терминал.
- **macOS:** `brew install ffmpeg`

Проверка: `ffmpeg -version`. Затем снова `python main.py --check` — должна появиться зелёная галочка у ffmpeg.

Видео для Telegram должно быть не больше 50 МБ — бот сам ужимает трейлер до 720p и не длиннее 150 секунд (`MAX_VIDEO_SECONDS`).

### Шаг 8. Запустите бота

```
python main.py
```
Бот работает, пока открыто окно терминала. Остановить — `Ctrl+C`. Журнал работы пишется на экран и в файл `logs/bot.log`.

Чтобы он работал **постоянно**, даже когда ваш компьютер выключен, его нужно запустить на сервере (VPS). Ниже — пять вариантов.

## Как оставить бота работать постоянно

### Вариант А. Арендованный сервер (VPS) на Linux — самый надёжный

Подойдёт самый дешёвый сервер с Ubuntu 22.04/24.04 (обычно несколько долларов или евро в месяц; одного ядра и 1 ГБ памяти хватит, для обработки трейлеров лучше 2 ГБ). Бесплатные «вечные» тарифы у некоторых облаков бывают, но условия и наличие мест меняются — проверяйте на сайте провайдера. Обычные бесплатные хостинги для сайтов или «засыпающие» сервисы для бота не подходят: ему нужно работать без перерывов.

1. Подключитесь к серверу по SSH (данные пришлёт провайдер): `ssh имя@адрес`.
2. Поставьте нужное:
   ```
   sudo apt update && sudo apt install -y python3 python3-venv python3-pip ffmpeg unzip
   ```
3. Загрузите проект на сервер. Например, с вашего компьютера: `scp game-news-bot.zip имя@адрес:~/` — а на сервере `unzip game-news-bot.zip`.
4. На сервере в папке проекта:
   ```
   cd ~/game-news-bot
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   nano .env            # впишите токен и канал; сохранить: Ctrl+O, Enter; выйти: Ctrl+X
   python main.py --check
   python main.py --once
   ```
5. Настройте автозапуск. Откройте файл `deploy/gamebot.service` (`nano deploy/gamebot.service`) и замените `ВАШ_ПОЛЬЗОВАТЕЛЬ` на ваше имя пользователя на сервере (его покажет команда `whoami`). Затем:
   ```
   sudo cp deploy/gamebot.service /etc/systemd/system/gamebot.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now gamebot
   ```
6. Готово. Бот запускается вместе с сервером и перезапускается сам, если упадёт. Полезные команды:
   ```
   sudo systemctl status gamebot       # работает ли
   journalctl -u gamebot -f            # смотреть журнал в реальном времени (выход: Ctrl+C)
   sudo systemctl restart gamebot      # перезапустить после изменения .env
   ```

### Вариант Б. Бесплатный сервер Oracle Cloud (Always Free)

У Oracle есть тариф **Always Free** — виртуальная машина, которая бесплатна не пробный период, а всё время, пока существует аккаунт. Для этого бота этого более чем достаточно.

1. **Регистрация.** Зайдите на [oracle.com/cloud/free](https://www.oracle.com/cloud/free/) и создайте аккаунт. Для проверки Oracle попросит привязать карту (снимается и возвращается около $1). Выбирайте «домашний регион» поближе к вам (например, Frankfurt или Amsterdam) — бесплатные ресурсы работают именно в нём.
2. **Создайте машину.** Меню → Compute → Instances → Create instance. Что выбрать:
   - **Образ:** Ubuntu (22.04 или 24.04).
   - **Форма (Shape):** `VM.Standard.E2.1.Micro` (AMD, 1 ГБ памяти) — тоже бесплатна, но для ffmpeg тесновато. Лучше `VM.Standard.A1.Flex` (ARM, 1–2 OCPU и 6–12 ГБ): этот объём памяти по-прежнему попадает в бесплатный лимит.
   - **SSH-ключ:** «Generate a key pair» и **скачайте приватный ключ** — без него на сервер не войти.
   - Остальное оставьте по умолчанию, публичный IP будет выдан автоматически.
3. **Подключитесь.** На Windows удобнее в PowerShell:
   ```
   ssh -i путь\к\ключу ubuntu@ПУБЛИЧНЫЙ_IP
   ```
4. **Установите и загрузите проект** (по одной строке):
   ```
   sudo apt update && sudo apt install -y python3 python3-venv python3-pip ffmpeg git
   git clone АДРЕС_РЕПОЗИТОРИЯ game-news-bot
   cd game-news-bot
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   nano .env          # впишите TELEGRAM_BOT_TOKEN и TELEGRAM_CHANNEL_ID (Ctrl+O, Enter, Ctrl+X)
   python main.py --check
   ```
   Папку можно и просто залить с компьютера через WinSCP, если Git не хотите.
5. **Автозапуск**, чтобы бот работал сам и поднимался после перезагрузки сервера:
   ```
   whoami                                  # покажет имя пользователя, обычно ubuntu
   nano deploy/gamebot.service             # замените ВАШ_ПОЛЬЗОВАТЕЛЬ на это имя (в двух местах)
   sudo cp deploy/gamebot.service /etc/systemd/system/gamebot.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now gamebot
   journalctl -u gamebot -f                # смотреть журнал (выход: Ctrl+C)
   ```

**Два нюанса Oracle, о которых лучше знать заранее:**

- **«Out of host capacity»** при создании ARM-машины означает, что в вашем регионе временно нет свободных бесплатных мощностей. Попробуйте другой availability domain или позже. AMD-форма (`E2.1.Micro`) доступна почти всегда, но на ней меньше памяти.
- **Oracle может забрать простаивающий сервер.** Если за 7 дней загрузка процессора, сети и памяти почти всегда ниже 20%, бесплатную машину могут освободить. Наш бот как раз работает «всплесками» (пост раз в 90 минут), поэтому на AMD-форме есть риск. Он невелик, если бот действительно постит, — но если канал будет долго молчать, лучше держать на сервере что-то ещё или перейти на ARM-форму с большей памятью (там порог по памяти не применяется). Просто не удивляйтесь, если однажды инстанс исчезнет, и держите `.env` скопированным.

### Вариант В. Docker

Если на сервере или хостинге уже есть Docker:
```
cp .env.example .env     # и заполните .env
docker compose up -d --build
docker compose logs -f
```
ffmpeg внутри образа уже есть. Память бота хранится в папке `data/`.

### Вариант Г. Старый Android-телефон (через Termux) — тоже бесплатно

Подойдёт **любой телефон с Android 7 или новее**. На телефонах с Android 5–6 Termux работает, но современные пакеты (в том числе Python) для них больше не выпускают — практически это тупик. Версию Android смотрите в настройках телефона.

📖 **Подробная пошаговая инструкция со всеми настройками Android: [`deploy/TERMUX.md`](deploy/TERMUX.md)**

Что понадобится: сам телефон, Wi-Fi и зарядка. Termux — это терминал для Android, в нём можно запустить нашего бота почти так же, как на компьютере.

1. **Поставьте Termux.** Скачайте из [F-Droid](https://f-droid.org/packages/com.termux/) **или** с [github.com/termux/termux-app](https://github.com/termux/termux-app/releases) (файлы `apt-android-7`). Версию из Google Play лучше не брать — она помечена как экспериментальная.
2. **Закиньте проект на телефон.** Проще всего — распаковать архив прямо в память телефона, затем в Termux дать доступ к файлам командой `termux-setup-storage` и перейти в папку, например `cd /sdcard/game-news-bot`.
3. **Установите всё одной командой:**
   ```
   bash deploy/termux-setup.sh
   ```
   Скрипт поставит Python, ffmpeg, библиотеку картинок и нужные пакеты проекта.
4. **Заполните `.env`** (токен и канал) и проверьте: `nano .env`, затем `python main.py --check`.
5. **Запустите так, чтобы бот работал при выключенном экране:**
   ```
   termux-wake-lock
   nohup python main.py >> logs/termux.log 2>&1 &
   ```
   Остановить: `pkill -f "python main.py"`.

**Чтобы Android не убивал бота** (это главная морока с телефонами):

- Разрешите Termux работу в фоне: Настройки → Приложения → Termux → Батарея → **«Без ограничений»**.
- На **Android 12 и новее** Android любит прибивать фоновые процессы и выкидывать сообщение `[Process completed (signal 9)]`. Включите в «Для разработчиков» пункт **«Отключить ограничения дочерних процессов»**. Подробности: [dontkillmyapp.com](https://dontkillmyapp.com/).
- Команда `termux-wake-lock` (из скрипта) держит процесс во время сна экрана.
- Чтобы бот сам поднимался после перезагрузки телефона, поставьте **Termux:Boot** (из F-Droid) и положите скрипт запуска в папку `~/.termux/boot/`.

**Советы для слабого телефона:** поставьте `SEND_TRAILERS=false` в `.env` — обработка видео самая тяжёлая, без неё посты всё равно выйдут со скриншотами. И не ждите чудес: телефон подходит как «бесплатно и уже есть под рукой», но постоянно включённый сервер надёжнее.

### Вариант Д. Свой компьютер (проще всего, но не «навсегда»)

Бот работает, пока компьютер включён и открыто окно с `python main.py`. На Windows можно добавить запуск при входе в систему через «Планировщик заданий» (программа: `venv\Scripts\python.exe`, аргумент: `main.py`, «Рабочая папка» — папка проекта).

## Необязательные бесплатные дополнения

Бот отлично работает и без них.

**ИИ-перевод (чтобы брать новости с английских сайтов и переводить описания игр без русского текста).**
Нужен ключ любого сервиса с «OpenAI-совместимым» API. У нескольких сервисов (например, Google AI Studio, Groq) есть бесплатные тарифы с ограничениями — условия меняются, смотрите на сайте. В `.env` заполните `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` (подсказки — в самом файле), а в `feeds.txt` уберите `#` перед нужными английскими лентами. Без ИИ у игр без русского описания в посте будет строка «Жанр … Разработчик …».

**Ссылка на трейлер с YouTube.** Если видео-трейлер получить не вышло (нет ffmpeg или Steam не дал поток), бот может найти официальный ролик через YouTube Data API. Ключ бесплатный (Google Cloud Console → «Включить API» → YouTube Data API v3 → «Создать ключ API»), вписывается в `YOUTUBE_API_KEY`. В пределах дневной квоты это бесплатно.

## Стиль постов

Бот умеет оформлять посты в трёх стилях — как у популярных игровых каналов. Переключается одной строкой в `.env` (`POST_STYLE`) и перезапуском.

| Стиль | Как выглядит | Как у канала |
|---|---|---|
| `prepod` (по умолчанию) | Строгий жирный заголовок, 1–2 предложения, строка с ценой, ссылка, подпись `@канал`. Без лишних эмодзи | «ПРЕПОД STEAM» |
| `stars` | Заголовок + факты пунктами `•`, подпись `🌟 @канал ✨` | «PlayStation Stars» |
| `platforma` | Эмодзи перед заголовком, пункты `🤩`, вопрос читателям в конце, подпись `@канал🤩` | «Платформа» |

Посмотреть результат, ничего не публикуя:

```
python main.py --once --dry-run
```

Понравился другой стиль — поменяйте `POST_STYLE` в `.env`, перезапустите бота и снова запустите `--once --dry-run`.

## Как бот следит за новостями

Кроме планового поста раз в `POST_INTERVAL_MINUTES` минут, бот каждые `POLL_SECONDS` секунд проверяет ленты и ищет «горячие» темы. Если находит — публикует сразу, не дожидаясь расписания.

Интересность складывается из свежести новости и веса темы: GTA, Half-Life, Valve, Nintendo, раздачи, отмены, скандалы, утечки и т.п. дают бонус. Обычные новости без заметных тем проходят только по расписанию.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `HOT_NEWS` | `true` | Включает режим горячих новостей |
| `HOT_MIN_SCORE` | `5.0` | Порог: ниже — реже внеплановые посты, выше — чаще |
| `HOT_MIN_GAP_MINUTES` | `25` | Минимальная пауза между любыми постами |
| `POLL_SECONDS` | `600` | Как часто проверять ленты (10 минут) |

Защита от спама встроена: не чаще одной публикации в `HOT_MIN_GAP_MINUTES` минут, не больше `MAX_POSTS_PER_DAY` в сутки, а вторую новость про ту же тему (например, ещё один материал про закрытие BioWare) бот пропустит в течение 6 часов.

Посмотреть, что бот считает горячим прямо сейчас, ничего не публикуя:

```
python -c "from gamebot.config import load_config; from gamebot.engine import Bot; from gamebot import hotness; b=Bot(load_config(), dry_run=True); b.post_hot(b.rank(b.collect()))"
```

## Как растить канал (и чего бот делать не может)

Важно понимать честно: **Telegram не даёт боту самому добавлять подписчиков.** Такого метода в Bot API нет — ни у этого бота, ни у любого другого. Всё, что делают «боты для набора подписчиков», — это либо рассылки с вашего личного аккаунта (спам), либо покупные пустые аккаунты. И за то, и за другое Telegram наказывает: ограничивает аккаунт, срезает охваты канала и может заблокировать его.

Что бот **умеет** (включено по умолчанию):

- **Кнопка «Подписаться на канал»** под каждым постом. Бот сам создаёт пригласительную ссылку — от вас ничего не нужно.
- **Статистика входов.** Бот замечает каждого нового подписчика и помнит, по какой ссылке он пришёл. Посмотреть: `python main.py --stats`.
- Свои пригласительные ссылки под разные источники можно создавать и вручную, чтобы понимать, что работает: например `post` (кнопка под постами), `wap` (взаимопиар), `ads` (реклама). В `.env` при желании включите `TRACK_JOINS=true` (по умолчанию включено).

Что растёт канал по-настоящему (делается руками):

1. **Контент и регулярность.** Понятное оформление, свежие новости, предсказуемое расписание — люди остаются и зовут других.
2. **Привязанная группа обсуждений.** Включите её в настройках канала: комментарии дают вовлечённость и рост.
3. **Взаимопиар.** Договоритесь с похожими каналами об обмене постами (можно договориться о взаимных упоминаниях).
4. **Реклама и каталоги.** Закупка рекламы у других каналов, Telegram Ads, попадание в каталоги каналов.
5. **Понятное описание канала** с ключевыми словами — чтобы вас находили через поиск в Telegram.

## Как поменять поведение

| Что хочется | Что менять |
|---|---|
| Чаще/реже публиковать | `POST_INTERVAL_MINUTES` в `.env` |
| Чтобы бот молчал ночью | `QUIET_HOURS=0-8` |
| Убрать раздачи или скидки | `STEAM_KINDS` (оставьте нужное из `release,free,discount,upcoming`) |
| Другие страны в ценах | `PRICE_REGIONS=ru,kz,ua,de,us` (коды стран Steam) |
| Больше/меньше скриншотов | `MAX_SCREENSHOTS` |
| Добавить/убрать новостные сайты | файл `feeds.txt` |
| Кнопка «Подписаться» под постами | `SUBSCRIBE_BUTTON` и `SUBSCRIBE_BUTTON_TEXT` в `.env` |
| Внешний вид постов (3 стиля) | `POST_STYLE=prepod` / `stars` / `platforma` |
| Частота постов | `POST_INTERVAL_MINUTES`, `MAX_POSTS_PER_DAY` |
| Горячие новости вне расписания | `HOT_NEWS`, `HOT_MIN_SCORE`, `HOT_MIN_GAP_MINUTES`, `POLL_SECONDS` |
| Вопрос читателям в конце поста | `POST_QUESTION` (только для стиля `platforma`) |
| Узнать, откуда приходят подписчики | `python main.py --stats` |
| Без эмодзи | `USE_EMOJI=false` |
| Изменить текст постов | функции `steam_post_text` и `news_post_text` в `gamebot/formatting.py` |

После любых правок `.env` перезапустите бота (`sudo systemctl restart gamebot` или `docker compose restart`).

## Если что-то не работает

- **`python main.py --check` — первое, что нужно запустить.** Он называет проблему по-русски.
- **«Forbidden / chat not found / not enough rights»** — бот не добавлен в канал администратором с правом публикации, либо неверно указан `TELEGRAM_CHANNEL_ID`.
- **Посты без видео** — не установлен ffmpeg (шаг 7) или у этой игры нет трейлера.
- **Лента «не открылась»** — сайт поменял адрес ленты. Найдите новый на сайте или отключите строку в `feeds.txt`.
- **Бот молчит** — смотрите `logs/bot.log`. Возможно, идут «тихие часы», достигнут дневной лимит постов или пока нет новых материалов (бот сам повторит попытку через `RETRY_MINUTES`).
- **Хочу, чтобы бот опубликовал ещё раз то, что уже было** — удалите файл `data/bot.db` (память сбросится).

## Важное, о чём стоит знать честно

- **Steam.** Бот использует публичные адреса магазина Steam, которые сайт сам использует для своих страниц. Valve не обещает, что они не изменятся. Если что-то изменится, бот продолжит работать на RSS и напишет в журнал о проблеме со Steam. Раньше Steam отдавал трейлеры обычными mp4, сейчас — потоком; бот умеет и то и другое.
- **Авторские права.** Бот публикует заголовок, короткий пересказ и ссылку на источник — это обычная практика новостных каналов. Скриншоты и трейлеры Steam — материалы издателей игр, картинки к новостям берутся с их же страниц. Если канал коммерческий, имеет смысл самому убедиться, что вас устраивают такие условия.
- **Telegram.** У Telegram есть лимиты: подпись к посту — 1024 символа, видео от бота — до 50 МБ, частые публикации могут вызвать ожидание. Бот учитывает это и подстраивается.
- **Контент 18+** по умолчанию не публикуется (`SKIP_ADULT=true`), чтобы канал не заблокировали.
