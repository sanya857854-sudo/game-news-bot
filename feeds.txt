# RSS-ленты, из которых бот берёт новости.
# Формат строки:   язык | название | адрес ленты
# Строки, начинающиеся с #, бот игнорирует. Чтобы отключить ленту — поставьте # в начале строки.
#
# Проверить все ленты разом (какие открываются, какие нет):   python main.py --check
# Если лента не открылась, бот сам делает паузу (15 минут, потом дольше — до 6 часов) и пробует снова,
# поэтому один «упавший» сайт остальных не тормозит. Адреса лент иногда меняются — тогда просто поправьте строку.
